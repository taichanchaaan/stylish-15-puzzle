# Stylish 15-Puzzle

A modern and stylish 15-puzzle game built with React, TypeScript, and Tailwind CSS.
This project was developed using a Spec-Driven Development approach.

## Live Demo

You can play the game here: https://taichanchaaan.github.io/stylish-15-puzzle

## Features

*   Modern and clean UI
*   Smooth animations with Framer Motion
*   Responsive design
*   Built with TypeScript for type safety

## Development

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

### Installation

1.  Clone the repository.
2.  Navigate to the `frontend` directory:
    ```bash
    cd frontend
    ```
3.  Install the dependencies:
    ```bash
    npm install
    ```

### Running the application

To start the development server, run:
```bash
npm start
```
The application will be available at `http://localhost:3000`.

### Building the application

To create a production build, run:
```bash
npm run build
```
The built files will be in the `frontend/build` directory.

### Deployment

This project is deployed to GitHub Pages. To deploy a new version, run:
```bash
npm run deploy
```

## Project Structure

*   `/specs`: Contains the specification, planning, and task documents for the features.
*   `/frontend`: Contains the React application source code.
